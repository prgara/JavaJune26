Collections ---> it is a framework to store and manipulate the group of objects.
It also give various methods to work on.
- List --- ArrayList, LinkedList
- Set
- Queue
- Map

- Collections work with objects only (non-primitive)

Wrapper classes -> It provides a way to use primitive data type as an object

int --->Integer
byte ---> Byte
long ---> Long
double ---> Double
boolean ---> Boolean

Boxing  ---> primitive to wrapper
Unboxing ---> wrapper object to primitive


Generics ----> It enforces single type using angle brackets. It promotes type safety as well as flexibility.
